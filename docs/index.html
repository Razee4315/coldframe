coldframe renders your Remotion videos on free GitHub machines, up to 20 at once, and brings the MP4 back to you.

  • Every frame checked
  • Free on public repos

Needs Node.js 18+ and the GitHub CLI.

One video in. One MP4 out.

Normally your laptop renders every frame, one by one. It gets hot.

  1. Split: your video is cut into 8 equal pieces.
  2. Render: 8 GitHub machines render their piece at the same time.
  3. Join: the pieces are joined into one MP4 and every frame is counted.

Claude Code checks your project, installs what's missing, connects GitHub and runs setup. It asks you before it creates a repo or starts a render.

Prompt for Claude Code
Set up coldframe in this project so my Remotion videos render in the cloud on free GitHub machines instead of on this computer. coldframe: https://github.com/Razee4315/coldframe

Do everything for me, one step at a time, and tell me briefly what you're doing:

1. Check that this folder is a Remotion project (package.json lists "remotion"). If not, stop and ask me where my project is.
2. Check that Node.js is 18 or newer. If package-lock.json is missing, run npm install.
3. Check the GitHub CLI with `gh --version`. If it's missing, install it (Windows: winget install GitHub.cli, macOS: brew install gh, Linux: https://cli.github.com). If this terminal can't find it after installing, use its full path.
4. Check `gh auth status`. If I'm not signed in, ask me to run this in my own terminal, and wait until I say it's done:
   gh auth login --web --git-protocol https --scopes workflow
5. If this folder isn't on GitHub yet (no github.com "origin" remote), ask me: public repo (renders free, no limit) or private (2,000 free minutes a month)? Then run git init -b main if needed, commit everything, and create and push the repo with:
   gh repo create <folder-name> --public (or --private) --source . --push
6. Run: npx github:Razee4315/coldframe setup
   It adds the render workflow and Claude Code skills, then commits and pushes them. If it stops with an error, fix the cause and run it again.
7. List my compositions with npx remotion compositions and show me their ids. Ask me before rendering, then render the one I pick with:
   npx github:Razee4315/coldframe render <CompositionId>
   The MP4 is saved in out/cloud/.

End with a short summary of what changed in my project.

Questions.

Something else? Ask on GitHub.

Is it really free?

Yes, on public repos. Private repos get 2,000 free machine-minutes a month, and each machine counts separately. You're never charged unless you add a payment method.

Is it faster than my laptop?

Not always. Each machine takes about 40 s to start, so short videos are quicker at home. The win is that your computer stays free while long videos render. 3D (WebGL) is much slower there, because the machines have no GPU.

Will the joins between pieces show?

No. Pieces are joined without re-encoding and the audio joins sample-exactly. If the frame count is wrong, the run fails instead of giving you a broken file.

What does the Claude Code prompt change?

Only what's written in it: it may install the GitHub CLI, put your project on GitHub if you say yes, and run coldframe setup, which adds a workflow file and Claude Code skills. You can read the whole prompt above before you paste it.

What about Remotion's license?

coldframe is MIT. Remotion is free for individuals and teams of up to 3; larger companies need a company license.
